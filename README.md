# Imersão em Engenharia de Software - Alura & Google Ai Studio & Google Antigravity


Esse é o repositório central da Imersão em Engenharia de Software com IA da Alura (de 26/10/2026 à 03/11/2026).

Aqui estão reunindos aqui dois dos desafios práticos desenvolvidos durante a Imersão. Cada desafio explora uma etapa da formação de um desenvolvedor na era da inteligência artificial: desde lógica fundamental e refatoração com IA até a criação de aplicações web completas com testes automatizados.

---


## Desafio 1: Calculadora básica em Python 

O primeiro desafio deste repositório consiste em uma calculadora com as quatro operações básicas desenvolvida em Python, integrada com as capacidades do Google AI Studio para explorar conceitos fundamentais de desenvolvimento.


### Conceitos Aplicados

* Lógica de programação: Estruturação do raciocínio lógico para a resolução do problema.

* Funções modulares (def): Organização e encapsulamento do código em blocos reutilizáveis.

* **Controle de fluxo (if/elif/else): Tomada de decisões com base nas entradas fornecidas.

* Tratamento de divisão por zero: Tratamento de erros e exceções para garantir a estabilidade do script.

---

## Como Executar 

1. Certifique-se de ter o Python instalado em sua máquina

2. Execute o script diretamente pelo terminal:
```bash
python calculadora.py
```

## Desafio 2: Evolução da calculadora com o Google Antigravity

Objetivos: Simular o fluxo real de Engenharia de Software através de 3 etapas:

I. Explorar: Mapear a arquitetura e responsabilidades dos módulos existentes.

II. Evoluir: Implementar o suporte completo a cálculos percentuais (%).

III Testar: Validar cenários de borda e garantir ausência de regressões nas funções anteriores.


Nesse desafio, dei uma turbinada na calculadora, acrescentando a função de porcentagem. Foram feitas pequenas alterações no código para adicionar essa nova função.


## Como Executar 

Do mesmo jeito que a calculadora básica foi executada:

1. Certifique-se que o Python está devidamente instalado em sua máquina 

2. Execute o script diretamente pelo terminal:
```bash
python calculadora.py
```
